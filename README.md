# 求职匹配助手

基于简历的求职辅助演示：解析能力画像 → 岗位匹配与证据覆盖 → 简历诊断 → 多轮模拟面试。未配置大模型密钥时走本地规则，页面与接口可完整演示；配置 OpenAI 兼容接口后，同一条链路改走对话模型。

## 功能

- **学历切换**：本科 / 硕士，影响画像与岗位硬性筛选
- **能力画像**：从简历文本提取技能、经历、意向等结构化信息
- **岗位匹配**：对内嵌演示岗位库（约 12 条，偏计算机与电气方向）排序；展示硬性条件、需求覆盖与证据片段
- **简历诊断**：针对所选岗位给出结构问题、关键词缺口与改写建议
- **模拟面试**：围绕岗位与证据进行三轮问答，结束后给出评分
- **离线可跑**：未配置 `LLM_API_KEY` 时使用本地规则，不依赖外部模型

当前范围刻意保持精简：无账号体系、无辅导员后台、无简历 OCR / 文件解析；岗位数据为代码内嵌演示集，非实时招聘源。

页面内置三份示例简历，可直接点选用。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 后端 | Go（标准库 `net/http`），无第三方依赖 |
| 前端 | React 19 · TypeScript · Vite |
| 可选模型 | OpenAI 兼容 Chat Completions（如阿里云百炼、火山方舟）；可选 Embedding |

## 快速开始

需本机已安装 **Go** 与 **Node.js**（建议 18+）。

**1. 启动后端**（默认 `http://127.0.0.1:8080`）

```bash
cd backend
cp .env.example .env   # 需要大模型时再填写 LLM_API_KEY 等
go run ./cmd/server
```

**2. 启动前端**（默认 `http://127.0.0.1:5173`）

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 http://127.0.0.1:5173 。开发模式下 Vite 将 `/api` 代理到 `8080`，前后端可分开起、同源访问。

健康检查：`GET http://127.0.0.1:8080/api/health`，响应中的 `mode` 为 `offline` 或 `llm`。

## 环境变量

复制 `backend/.env.example` 为 `backend/.env`（已在 `.gitignore` 中忽略，**请勿提交真实密钥**）。

| 变量 | 说明 |
| --- | --- |
| `LLM_BASE_URL` | OpenAI 兼容基址。示例为百炼；换方舟时改为对应地址 |
| `LLM_API_KEY` | API Key；留空则全程本地规则（offline） |
| `LLM_MODEL` | 对话模型名（百炼如 `qwen-plus`；方舟填接入点 ID） |
| `EMBEDDING_MODEL` | 可选。留空时岗位召回用字面相似度；画像 / 解释 / 诊断 / 面试仍可走对话模型 |
| `PORT` | 后端端口，默认 `8080` |

从 `backend/` 或仓库根目录启动均可加载 `.env`（优先已有环境变量，不覆盖）。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/health` | 服务状态与当前模式 |
| `GET` | `/api/jobs` | 演示岗位列表 |
| `POST` | `/api/profile` | 简历 → 能力画像（`degree` + `resume`） |
| `POST` | `/api/match` | 画像 → 岗位排序与证据（`resume` + `profile`） |
| `POST` | `/api/diagnose` | 针对岗位的简历诊断（`resume`、`profile`、`jobId`、`evidence`） |
| `POST` | `/api/interview` | 模拟面试一轮或终评（同上 + `messages`） |

请求 / 响应均为 JSON。单次请求体上限约 1MB。服务端无会话存储：状态由前端在当次浏览中持有。

## 隐私与使用说明

- 岗位与示例简历均为演示数据，不代表真实招聘结果。
- 后端无状态、不落库：上传的简历等内容仅用于当次请求处理，不在服务端持久化。
- 会话进度保存在浏览器前端内存中，刷新页面会丢失。
- 若配置了大模型，请求内容会发往你所填写的 `LLM_BASE_URL` 对应服务；请自行评估合规与隐私策略。
- 本仓库面向本地演示与二次开发，生产环境请自行补充鉴权、限流与数据治理。
